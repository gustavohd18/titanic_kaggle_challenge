# Titanic Kaggle Challenge

## Overview
This project tackles the **Titanic - Machine Learning from Disaster** Kaggle challenge. The primary goal is to build a predictive model using machine learning and deep learning techniques to determine which passengers survived the Titanic shipwreck based on historical data. Additionally, we perform Exploratory Data Analysis (EDA) to uncover insights, particularly examining whether economic status (e.g., wealth) influenced survival rates. An individual goal was to build a model with at least 80% accuracy and to achieve a minimum accuracy of 75% on Kaggle's validation, and we were able to reach that result.
link: https://www.kaggle.com/competitions/titanic

## Project Structure
- **EDA (Exploratory Data Analysis)**: Analyzes the dataset to identify patterns, correlations, and trends, with a focus on understanding the relationship between survival and socio-economic factors like wealth or class.
- **Machine Learning and Deep Learning **: Implements various algorithms to predict survival outcomes, also applies neural network models too.

## Objectives
1. **Prediction**: Develop a model to accurately predict which passengers survived the Titanic disaster.
2. **Analysis**: Investigate whether wealth or higher economic status (e.g., first-class passengers) correlates with a higher likelihood of survival.
## Dependencies
- Python 3.x
- Pandas (Data Analysis)
- NumPy (Data Analysis)
- Scikit-learn (Machine learning)
- TensorFlow (for deep learning)
- Matplotlib/Seaborn (for visualization)
- Jupyter Notebook

## Usage
1. **EDA**: Open `eda_titanic.ipynb` to explore the data analysis and visualizations.
2. **Model Training**: Run `training.ipynb` for machine learning models and for deep learning experiments.
